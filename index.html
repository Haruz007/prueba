Cloud Computing Conexión remota

Cloud Computing

Modelo que permite acceder bajo demanda a recursos informáticos (servidores, almacenamiento, redes, software) a través de Internet, pagando solo por lo que se usa.

SaaS (Software as a Service)

Software listo para usar desde el navegador, sin instalar ni administrar nada. Ejemplo: Gmail, Microsoft 365.

PaaS (Platform as a Service)

Plataforma para desarrollar, probar y desplegar aplicaciones sin gestionar la infraestructura. Ejemplo: Google App Engine, Heroku.

IaaS (Infrastructure as a Service)

Infraestructura virtual (máquinas, redes, almacenamiento) que el usuario administra. Ejemplo: AWS EC2, Azure VM.

Virtualización

Tecnología que permite ejecutar varios sistemas operativos o servidores virtuales sobre un mismo hardware físico mediante un hipervisor (VMware, VirtualBox, Hyper-V).

Docker

Plataforma que empaqueta aplicaciones y sus dependencias en contenedores ligeros y portables, que se ejecutan igual en cualquier entorno.
