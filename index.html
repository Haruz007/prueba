Concepto Base

Cloud Computing (Computación en la Nube)

Es un modelo tecnológico que permite el acceso bajo demanda, a través de Internet, a un conjunto compartido de recursos informáticos configurables —como servidores, almacenamiento, bases de datos, redes y aplicaciones— sin necesidad de adquirir ni administrar hardware físico local, operando generalmente bajo un esquema de pago por uso.

Modelo de Servicio

SaaS (Software as a Service)

Software como Servicio: El proveedor aloja, mantiene y actualiza aplicaciones completas en la nube para que los usuarios accedan directamente desde un navegador web sin instalar nada localmente. Ejemplos: Google Workspace, Microsoft 365 y Salesforce.

Modelo de Servicio

PaaS (Platform as a Service)

Plataforma como Servicio: Proporciona un entorno completo en la nube con sistemas operativos, bases de datos y herramientas de desarrollo listas para crear, probar y desplegar aplicaciones sin gestionar la infraestructura subyacente. Ejemplos: Heroku y Google App Engine.

Modelo de Servicio

IaaS (Infrastructure as a Service)

Infraestructura como Servicio: Ofrece recursos informáticos fundamentales virtualizados (servidores, almacenamiento y redes) bajo demanda. El usuario administra los sistemas operativos y aplicaciones mientras el proveedor mantiene el hardware físico. Ejemplos: AWS EC2 y Azure.

Tecnología Base

Virtualización

Tecnología que permite crear representaciones virtuales de servidores, sistemas operativos, almacenamiento o redes mediante un software llamado hipervisor. Permite ejecutar múltiples máquinas virtuales independientes sobre un mismo servidor físico.

Contenedores

Docker

Plataforma de código abierto que automatiza el despliegue de aplicaciones dentro de contenedores ligeros y portátiles. Empaqueta el código junto con sus bibliotecas y dependencias, compartiendo el núcleo del sistema operativo para garantizar portabilidad total.
